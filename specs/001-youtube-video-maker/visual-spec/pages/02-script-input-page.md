# 文稿輸入頁面 (Script Input Page)

## 頁面概述

使用者輸入或貼上影片文稿的頁面,系統將驗證文稿長度並預估影片時長。

## 互動行為

### 文稿輸入驗證

**即時驗證** (debounce 500ms):

1. **文稿為空**:
   - 禁用「下一步」按鈕
   - 不顯示錯誤訊息

2. **文稿少於 10 字**:
   - 禁用「下一步」按鈕
   - 在輸入框下方顯示錯誤訊息:
     - 文字: "文稿過短,請至少輸入 10 字"
     - 顏色: #E03E3E
     - Icon: ✕

3. **文稿 10-49 字**:
   - 啟用「下一步」按鈕
   - 顯示警告訊息:
     - 文字: "文稿較短,建議至少 50 字以獲得更好的影片效果"
     - 顏色: #D9730D
     - Icon: ⚠

4. **文稿 ≥ 50 字 且 ≤ 7500 字** (約 30 分鐘):
   - 啟用「下一步」按鈕
   - 顯示正常統計資訊

5. **文稿 > 7500 字** (超過 30 分鐘):
   - 啟用「下一步」按鈕
   - 顯示警告訊息:
     - 文字: "文稿過長,預估影片長度超過 30 分鐘,可能影響生成速度和成本"
     - 顏色: #D9730D
     - Icon: ⚠

### 下一步處理流程

**點擊「下一步」按鈕後**:

1. **顯示處理中狀態**:
   ```
   ┌──────────────────────────────────────────────┐
   │  正在處理文稿...                              │
   │  ████████████░░░░░░░░░░░░░░░░░░░░ 0%         │
   │                                              │
   │  • 正在生成配音... (1/2)                     │
   └──────────────────────────────────────────────┘
   ```

2. **步驟 1: 語音合成** (呼叫 Google TTS API):
   - 顯示: "正在生成配音... (1/2)"
   - 進度: 0% → 50%
   - 請求格式: 見 API Contract (tts-api.yaml)
   - 輸出: 音檔 (.mp3) + 時間標記 (JSON)

3. **步驟 2: 腳本生成** (呼叫 Gemini API):
   - 顯示: "正在生成腳本... (2/2)"
   - 進度: 50% → 100%
   - 請求格式: 見 API Contract (gemini-api.yaml)
   - 輸出: 腳本 JSON (段落、時間、圖片提示詞)

4. **處理完成**:
   - 關閉進度對話框
   - 跳轉到「腳本編輯頁面」
   - 傳遞資料: 文稿、音檔路徑、時間標記、腳本 JSON

### 儲存專案功能

**點擊「儲存專案」按鈕**:

1. **開啟專案命名對話框**:
   ```
   ┌────────────────────────────────────┐
   │  儲存專案                       [✕] │
   ├────────────────────────────────────┤
   │  專案名稱                           │
   │  ┌──────────────────────────────┐  │
   │  │ 我的影片專案                  │  │
   │  └──────────────────────────────┘  │
   │  預設儲存至 ~/Documents/YTMaker3   │
   ├────────────────────────────────────┤
   │                     [取消] [儲存]  │
   └────────────────────────────────────┘
   ```

2. **儲存專案資料** (JSON 格式):
   ```json
   {
     "projectName": "我的影片專案",
     "createdAt": "2025-10-29T10:30:00Z",
     "updatedAt": "2025-10-29T10:30:00Z",
     "currentStage": "script-input",
     "scriptContent": "文稿內容...",
     "voiceId": "zh-TW-HsiaoChenNeural",
     "outputPath": "~/Documents/YTMaker3/我的影片專案",
     "audioFile": null,
     "scriptData": null
   }
   ```

3. **儲存成功**:
   - 顯示成功提示: "專案已儲存"
   - 更新頁面標題顯示專案名稱

## 錯誤處理

### API 錯誤

**Google TTS API 失敗**:
```
錯誤訊息: "無法連線到 Google TTS 服務"
說明: "請檢查網路連線和 API 金鑰設定後重試"
操作: [重試] [檢查設定] [取消]
```

**Gemini API 失敗**:
```
錯誤訊息: "無法生成腳本"
說明: "請檢查網路連線和 Gemini API 金鑰設定後重試"
操作: [重試] [檢查設定] [取消]
```

**API 金鑰無效**:
```
錯誤訊息: "{服務名稱} API 金鑰無效"
說明: "請前往設定頁面更新您的 API 金鑰"
操作: [前往設定] [取消]
```

### 網路錯誤

```
錯誤訊息: "網路連線失敗"
說明: "請檢查您的網路連線後重試"
操作: [重試] [取消]
```

### 檔案系統錯誤

**輸出位置無法存取**:
```
錯誤訊息: "無法存取所選位置"
說明: "請確認目錄存在且您有寫入權限,或選擇其他位置"
操作: [重新選擇] [取消]
```

## 鍵盤快捷鍵

```
Cmd+S: 儲存專案
Cmd+Enter: 下一步 (若已啟用)
Esc: 取消
```

## 無障礙

- 所有輸入框支援鍵盤導航
- 語音選擇支援方向鍵瀏覽
- 錯誤訊息使用 ARIA 屬性通知螢幕閱讀器
- Focus 樣式清晰可見
