## 互動行為

### 初始載入

**載入專案資料**:
1. 從專案檔案讀取所有資訊
2. 從 YouTube API 獲取影片詳細資訊
3. 載入影片縮圖
4. 計算 API 用量統計
5. 顯示完成頁面

### YouTube 影片操作

**在 YouTube 上觀看**:
1. 點擊按鈕或縮圖
2. 在預設瀏覽器中開啟 YouTube 影片
3. URL: `https://www.youtube.com/watch?v={videoId}`

**複製連結**:
1. 點擊「複製連結」按鈕或連結容器右側的複製圖示
2. 複製短連結到剪貼簿
3. 顯示成功提示: "連結已複製"
4. 提示 3 秒後自動消失

**分享**:
1. 點擊「分享」按鈕
2. 開啟分享選單 (macOS 原生分享表單)
3. 分享內容:
   - 標題: {影片標題}
   - URL: https://youtu.be/{videoId}
4. 支援分享到:
   - 郵件
   - 訊息
   - AirDrop
   - 社群媒體 (Twitter, Facebook 等)

### API 用量統計

**即時計算**:
- Gemini: 從回應中讀取 token 使用量
- Google TTS: 計算文稿字數
- Replicate: 計算生成的圖片數量
- D-ID: 計算對嘴影片總時長
- YouTube: 固定配額 1600 單位 (上傳操作)

**費用計算** (以當前價格為準):
- Gemini: 輸入 $0.00002/token + 輸出 $0.00006/token
- Google TTS: $0.000016/字
- Replicate: $0.10/張圖片 (FLUX 模型)
- D-ID: $0.06/秒
- YouTube: 免費 (但受每日配額限制)

**匯出 CSV**:
1. 點擊「匯出 CSV」按鈕
2. 開啟檔案儲存對話框
3. 預設檔名: "api-usage-{專案名稱}-{日期}.csv"
4. CSV 格式:
   ```csv
   服務,呼叫次數,用量詳情,費用 (USD)
   Gemini,1,"輸入: 500, 輸出: 1200",0.02
   Google TTS,1,500 字,0.01
   ...
   總計,,,0.83
   ```

### 專案檔案操作

**在 Finder 中開啟**:
1. 點擊「在 Finder 中開啟」按鈕
2. 開啟 macOS Finder
3. 導航到專案輸出目錄
4. 選中專案資料夾

**刪除專案檔案**:
1. 點擊「刪除專案檔案」按鈕
2. 顯示確認對話框:
   ```
   ┌────────────────────────────────────┐
   │  確認刪除                       [✕] │
   ├────────────────────────────────────┤
   │  確定要刪除此專案的所有檔案嗎?     │
   │                                    │
   │  此操作無法復原,將刪除:             │
   │  • 影片檔案                        │
   │  • 音檔                            │
   │  • 圖片                            │
   │  • 專案設定檔                      │
   │                                    │
   │  YouTube 上的影片不會被刪除。      │
   ├────────────────────────────────────┤
   │                    [取消] [確認刪除]│
   └────────────────────────────────────┘
   ```
3. 若確認:
   - 刪除專案輸出目錄下的所有檔案
   - 刪除專案 JSON 檔案
   - 顯示成功提示: "專案檔案已刪除"
   - 跳轉到首頁

### 後續操作

**建立新專案**:
1. 點擊「建立新專案」按鈕
2. 複製目前專案的設定:
   - 圖片風格
   - 字幕樣式
   - Logo (若有)
   - 輸出位置
3. 跳轉到文稿輸入頁面
4. 套用複製的設定

**回到首頁**:
1. 點擊「回到首頁」按鈕
2. 跳轉到首頁
3. 顯示完成的專案在「最近的專案」列表中

**儲存為範本**:
1. 點擊「儲存為範本」按鈕
2. 開啟範本命名對話框:
   ```
   ┌────────────────────────────────────┐
   │  儲存為範本                     [✕] │
   ├────────────────────────────────────┤
   │  範本名稱                           │
   │  ┌──────────────────────────────┐  │
   │  │ 我的預設樣式                  │  │
   │  └──────────────────────────────┘  │
   │                                    │
   │  將儲存以下設定:                   │
   │  • 圖片風格: 可愛插畫風格          │
   │  • 字幕樣式: 下方置中, 白色        │
   │  • Logo: 已設定                    │
   ├────────────────────────────────────┤
   │                     [取消] [儲存]  │
   └────────────────────────────────────┘
   ```
3. 若儲存:
   - 建立範本 JSON 檔案
   - 儲存到 `~/Library/Application Support/YTMaker3/templates/`
   - 顯示成功提示: "範本已儲存"

## 錯誤處理

### YouTube 資訊載入錯誤

**無法獲取影片資訊**:
```
錯誤訊息: "無法載入 YouTube 影片資訊"
說明: "請檢查網路連線或稍後再試"
操作: [重試] [略過]
```

**影片已被刪除**:
```
錯誤訊息: "影片不存在"
說明: "此影片可能已被刪除或設為私人"
操作: [確定]
```

### 檔案操作錯誤

**無法開啟 Finder**:
```
錯誤訊息: "無法開啟 Finder"
說明: "請手動前往專案位置: {路徑}"
操作: [複製路徑] [確定]
```

**刪除失敗**:
```
錯誤訊息: "刪除失敗"
說明: "部分檔案無法刪除,請檢查檔案權限"
操作: [重試] [在 Finder 中開啟]
```
