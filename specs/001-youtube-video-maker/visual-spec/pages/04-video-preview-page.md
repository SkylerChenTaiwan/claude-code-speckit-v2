預覽合成的影片,編輯字幕樣式、添加 Logo,並可下載任意圖片作為縮圖底圖。

## 互動行為

### 初始載入

**自動生成預覽影片**:
1. 載入所有生成的媒體資源
2. 使用 FFmpeg 快速合成預覽版影片 (低解析度)
3. 載入預覽影片到播放器
4. 載入專案中已儲存的字幕和 Logo 設定

**預設設定**:
- 字幕位置: 下方置中
- 字型: PingFang TC
- 字體大小: 32px
- 文字顏色: #FFFFFF
- 陰影顏色: #000000
- Logo: 無

### 字幕即時預覽

**任何字幕設定變更時**:
1. 更新預覽窗口中的字幕樣式
2. 即時顯示效果 (無需重新合成)
3. 使用 CSS 模擬最終效果
4. 自動儲存設定到專案

**支援的即時預覽**:
- 位置
- 字型
- 字體大小
- 文字顏色
- 陰影顏色
- 邊框顏色 (若設定)
- 底色 (若設定)

### Logo 拖曳定位

**啟用拖曳模式**:
- 滑鼠 hover 到預覽窗口中的 Logo 時
- 游標變為 "移動" 圖示
- Logo 顯示半透明選擇框

**拖曳操作**:
1. 按住 Logo 並拖曳
2. 即時更新 Logo 位置
3. 顯示座標提示 (X: {x}, Y: {y})
4. 釋放滑鼠後儲存座標到設定面板

**座標輸入**:
- 在設定面板中輸入 X, Y 座標
- 即時更新預覽窗口中的 Logo 位置
- 驗證範圍 (0 ≤ X, Y ≤ 影片尺寸)

### 影片播放控制

**播放按鈕**:
- 點擊: 開始播放影片
- 按鈕變為「暫停」
- 開始計時

**暫停按鈕**:
- 點擊: 暫停播放
- 按鈕變為「播放」
- 保持目前時間

**停止按鈕**:
- 點擊: 停止播放
- 時間重置為 0:00
- 按鈕變為「播放」

**時間軸** (可選實作):
- 顯示播放進度條
- 可拖曳跳轉到指定時間
- 顯示緩衝狀態

**音量控制**:
- 拖曳滑桿調整音量 (0% - 100%)
- 點擊圖示切換靜音
- 儲存音量設定到 localStorage

### 合成影片流程

**點擊「合成影片」按鈕後**:

1. **顯示合成進度對話框**:
   ```
   ┌──────────────────────────────────────────────┐
   │  正在合成影片...                              │
   │  ████████████████████████░░░░░░░░ 75%        │
   │                                              │
   │  • 正在合成影片... (FFmpeg)                  │
   │    預計剩餘時間: 2 分鐘                      │
   └──────────────────────────────────────────────┘
   ```

2. **FFmpeg 合成**:
   - 合併所有圖片、音檔、D-ID 影片
   - 套用字幕樣式 (使用 FFmpeg 字幕濾鏡)
   - 疊加 Logo (若有)
   - 輸出: 1920x1080, H.264, AAC
   - 進度: 0% → 100%

3. **合成完成**:
   - 關閉進度對話框
   - 顯示成功提示: "影片合成完成"
   - 跳轉到「YouTube 上傳頁面」
   - 傳遞資料: 影片路徑

## 錯誤處理

### 媒體資源錯誤

**缺少圖片**:
```
錯誤訊息: "缺少段落 {編號} 的圖片"
說明: "請返回腳本編輯頁面重新生成媒體資源"
操作: [返回腳本編輯] [取消]
```

**缺少音檔**:
```
錯誤訊息: "缺少配音檔案"
說明: "請返回文稿輸入頁面重新生成配音"
操作: [返回文稿輸入] [取消]
```

### 合成錯誤

**FFmpeg 合成失敗**:
```
錯誤訊息: "影片合成失敗"
說明: "請檢查媒體資源完整性和儲存空間後重試"
詳細錯誤: {FFmpeg 錯誤訊息}
操作: [重試] [查看日誌] [取消]
```

**儲存空間不足**:
```
錯誤訊息: "儲存空間不足"
說明: "合成影片需要至少 {所需空間} MB 的可用空間"
操作: [清理快取] [選擇其他位置] [取消]
```

### Logo 檔案錯誤

**檔案格式錯誤**:
```
錯誤訊息: "Logo 檔案格式不支援"
說明: "請使用 PNG 格式 (支援透明背景)"
操作: [重新上傳]
```

**檔案過大**:
```
錯誤訊息: "Logo 檔案過大"
說明: "請使用小於 2MB 的 PNG 檔案"
操作: [重新上傳]
```
