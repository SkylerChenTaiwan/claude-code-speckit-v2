# 共用元件規範

## 1. 頁面容器 (Page Container)

```
┌─────────────────────────────────────────────────────────────┐
│  [頁面標題]                                    [操作按鈕區]  │
│  次要說明文字 (淡灰色)                                       │
│                                                               │
│  ┌───────────────────────────────────────────────────────┐  │
│  │                                                         │  │
│  │  內容區域                                               │  │
│  │                                                         │  │
│  └───────────────────────────────────────────────────────┘  │
│                                                               │
│                                      [取消] [下一步 →]       │
└─────────────────────────────────────────────────────────────┘
```

### 規格
- **寬度**: 最大 1200px,螢幕中央對齊
- **內邊距**: 48px (上下) / 32px (左右)
- **背景**: #FFFFFF
- **標題字型**: Heading 1 (24px)
- **說明字型**: Body Small (13px, #9B9A97)
- **按鈕位置**: 右下角固定

### 底部按鈕規則
- **取消/上一步**: Secondary Button,左側
- **下一步/確認**: Primary Button,右側
- **按鈕間距**: 12px
- **鍵盤快捷鍵**:
  - Enter: 執行主要操作 (下一步)
  - Esc: 取消
  - Cmd+Z: 返回上一步

### 規格
