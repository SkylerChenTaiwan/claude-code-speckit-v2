# Feature Specification: YouTube 影片快速製作工具

**Feature Branch**: `001-youtube-video-maker`
**Created**: 2025-10-29
**Status**: Draft
**Input**: User description: "YouTube 影片快速製作工具 - macOS 桌面應用程式,支援 1-30 分鐘影片製作,使用 Google TTS、Gemini、Replicate FLUX、D-ID 等服務,提供完整的文稿到 YouTube 發布流程"

## Clarifications

### Session 2025-10-29

- Q: 專案檔案儲存格式 → A: JSON 格式 (.json) - 結構化,易於程式解析和擴展
- Q: 專案輸出檔案的預設儲存位置 → A: 使用者文件/YTMaker3 目錄 - 標準做法,易於備份和管理
- Q: 圖片快取儲存位置與容量管理 → A: 應用程式快取目錄 + 自動清理 - 符合 macOS 規範,自動管理空間
- Q: 批次製作時的並行處理策略 → A: 序列處理 - 一次處理一個,穩定可靠但較慢
- Q: API 金鑰的儲存與管理方式 → A: macOS Keychain - 系統級加密,安全且符合平台規範

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 基本影片製作與發布 (Priority: P1)

內容創作者想要快速將文字稿轉換成配音影片並上傳到 YouTube,無需手動處理語音合成、圖片生成和影片剪輯。

**Why this priority**: 這是核心價值主張,涵蓋從文稿輸入到 YouTube 發布的完整流程,是產品的最小可行功能。

**Independent Test**: 使用者可以輸入一段文稿(例如 500 字),選擇預設設定,成功生成並上傳一部帶有自動生成圖片、配音和字幕的影片到 YouTube。

**Acceptance Scenarios**:

1. **Given** 使用者在文稿輸入頁面貼上一段 300-500 字的繁體中文文稿, **When** 點擊「下一步」, **Then** 系統自動生成配音音檔並將文稿切分為段落,每段配有圖片描述提示詞
2. **Given** 系統已生成腳本, **When** 使用者在腳本編輯頁面選擇圖片風格(如「寫實風格」)並點擊「下一步」, **Then** 系統自動為每個段落生成 1920x1080 的圖片
3. **Given** 圖片已生成, **When** 使用者在影片編輯預覽頁面使用預設字幕設定並點擊「下一步」, **Then** 系統使用 FFmpeg 合成影片(包含圖片、配音、字幕、動畫效果),輸出 MP4 檔案
4. **Given** 影片已合成, **When** 使用者在 YouTube 上傳設定頁面完成 OAuth 認證並填寫標題、描述等基本資訊後點擊「上傳」, **Then** 影片成功上傳到指定的 YouTube 頻道
5. **Given** 影片上傳完成, **When** 系統顯示完成頁面, **Then** 使用者可以看到本次專案的 API 用量統計(Gemini、TTS、Replicate 的呼叫次數與費用)

### User Story 2 - 腳本客製化與進階編輯 (Priority: P2)

內容創作者希望能夠精細調整自動生成的腳本內容、圖片描述提示詞、時間軸,以及自訂字幕樣式和 Logo,以符合個人品牌風格。

**Why this priority**: 雖然自動化是核心價值,但客製化能力能顯著提升產出品質和使用者滿意度,是產品差異化的關鍵。

**Independent Test**: 使用者可以編輯自動生成的腳本(修改段落文字、調整時間、改寫圖片提示詞),自訂字幕樣式(字型、顏色、位置),上傳並定位 Logo,預覽效果後成功生成影片。

**Acceptance Scenarios**:

1. **Given** 系統已生成初始腳本, **When** 使用者在腳本編輯頁面修改某段落的圖片提示詞並調整段落時間, **Then** 修改即時反映在腳本預覽中,不影響其他段落
2. **Given** 使用者想要調整 Gemini 的圖片生成邏輯, **When** 點擊「查看/修改 system prompt」, **Then** 可以編輯 Gemini 的 system prompt 並套用到後續段落
3. **Given** 影片編輯預覽頁面已載入預設字幕, **When** 使用者調整字幕位置(如「底部中央」改為「頂部」)、修改字體大小、設定文字顏色和陰影效果, **Then** 預覽窗口即時顯示調整後的效果
4. **Given** 使用者上傳了 Logo 圖片, **When** 透過拖曳介面將 Logo 定位到畫面右下角, **Then** 預覽窗口即時顯示 Logo 位置,且合成後的影片包含該 Logo
5. **Given** 腳本中有 5 張生成的圖片, **When** 使用者在影片編輯頁面點擊任一張圖片的「下載」按鈕, **Then** 該圖片下載為 PNG 或 JPG 檔案供後續製作縮圖使用

---

### User Story 3 - 對嘴影片生成 (Priority: P3)

內容創作者想要在影片開頭或結尾使用虛擬人物對嘴片段,增加影片的個人化和吸引力。

**Why this priority**: 此為選配功能,提升影片質感但非核心需求,適合進階使用者或特定內容類型(如教學、品牌推廣)。

**Independent Test**: 使用者可以上傳一張 16:9 人像圖片,選擇「僅開頭第一段」使用 D-ID 對嘴,系統自動生成開頭的對嘴影片並整合到最終輸出中。

**Acceptance Scenarios**:

1. **Given** 使用者在腳本編輯頁面選擇「僅開頭第一段」對嘴選項, **When** 上傳符合 16:9 比例的人像圖片, **Then** 系統驗證圖片尺寸並顯示上傳成功提示
2. **Given** 使用者已設定對嘴選項並點擊「下一步」, **When** 系統執行圖片生成階段, **Then** 同時使用上傳的人像圖片和開頭段落的音檔呼叫 D-ID API 生成對嘴影片
3. **Given** D-ID 對嘴影片已生成, **When** 進入影片編輯預覽頁面, **Then** 預覽窗口顯示開頭使用對嘴影片、其他段落使用靜態圖片的組合效果
4. **Given** 使用者選擇「開頭+結尾」對嘴, **When** 系統合成最終影片, **Then** 影片的第一段和最後一段使用對嘴影片,中間段落使用生成的圖片

---

### User Story 4 - 專案管理與範本功能 (Priority: P2)

內容創作者需要儲存進行中的專案以便稍後繼續編輯,並希望能將常用的設定(字幕樣式、Logo 位置、圖片風格)儲存為範本,加速後續影片製作。

**Why this priority**: 對於高頻使用者或需要批次製作的情境至關重要,可大幅提升工作效率和使用體驗。

**Independent Test**: 使用者可以在任意製作階段儲存專案,關閉應用程式後重新開啟並載入該專案繼續編輯;使用者可以將字幕樣式和 Logo 設定儲存為範本,並在新專案中一鍵套用。

**Acceptance Scenarios**:

1. **Given** 使用者正在腳本編輯階段, **When** 點擊「儲存專案」, **Then** 系統將當前所有設定儲存為 JSON 格式檔案到使用者選擇的位置(預設為使用者文件/YTMaker3)
2. **Given** 使用者之前儲存了一個專案, **When** 在應用程式主頁點擊「載入專案」並選擇該 JSON 檔案, **Then** 系統載入所有設定並跳轉到上次離開的製作階段
3. **Given** 使用者首次建立專案, **When** 系統提示選擇輸出檔案儲存位置, **Then** 預設顯示使用者文件/YTMaker3 目錄,使用者可接受或修改
4. **Given** 使用者已在上個專案選擇儲存到桌面/MyVideos, **When** 建立新專案並到達儲存位置選擇步驟, **Then** 系統預設顯示桌面/MyVideos,使用者可沿用或修改
5. **Given** 使用者在影片編輯預覽頁面完成字幕和 Logo 設定, **When** 點擊「儲存為範本」並命名為「我的預設樣式」, **Then** 系統儲存字幕樣式(字型、顏色、位置等)和 Logo 位置資訊
6. **Given** 使用者在新專案的影片編輯頁面, **When** 選擇「套用範本:我的預設樣式」, **Then** 所有字幕和 Logo 設定自動套用,使用者只需微調即可

---

### User Story 5 - 批次製作與排程上傳 (Priority: P3)

內容創作者想要一次匯入多個文稿,套用相同的範本設定,批次生成影片並排程在不同時間自動上傳到 YouTube。

**Why this priority**: 此為進階效率功能,適合專業內容創作者或行銷團隊,但對一般使用者非必要。

**Independent Test**: 使用者可以匯入 5 個文稿檔案,選擇套用既有範本,系統批次生成 5 部影片並根據設定的時間排程(如每日上午 10 點發布一部)自動上傳。

**Acceptance Scenarios**:

1. **Given** 使用者在批次製作頁面, **When** 匯入 5 個 .txt 或 .md 文稿檔案, **Then** 系統顯示 5 個專案列表,每個專案對應一個文稿
2. **Given** 批次專案列表已建立, **When** 使用者選擇「套用範本:我的預設樣式」到所有專案, **Then** 所有專案自動套用該範本的字幕、Logo 和圖片風格設定
3. **Given** 使用者點擊「批次生成」, **When** 系統採用序列處理策略依序處理每個專案(一次處理一個,完成後才開始下一個), **Then** 每個專案完成後顯示進度(如「正在處理: 2/5」),當前專案的處理階段(語音合成/腳本生成/圖片生成/影片合成)即時更新
4. **Given** 批次生成過程中某個專案的圖片生成失敗, **When** 系統已重試 2 次仍失敗, **Then** 該專案標記為失敗,系統繼續處理下一個專案,最後顯示成功和失敗的專案列表
5. **Given** 5 部影片已生成, **When** 使用者在批次上傳設定頁面為每部影片設定不同的發布時間(如第一部:今天下午 3 點、第二部:明天上午 10 點), **Then** 系統記錄排程並在指定時間自動上傳到 YouTube
6. **Given** 批次上傳正在進行, **When** 使用者查看批次上傳狀態頁面, **Then** 顯示每部影片的上傳狀態(已上傳、排程中、等待中)和剩餘排程時間

---

### Edge Cases

- **當使用者首次啟動應用程式且未設定 API 金鑰時**: 系統顯示歡迎頁面並引導使用者前往 API 金鑰設定介面,提示需要輸入的各項金鑰(Google TTS、Gemini、Replicate、D-ID、YouTube),說明如何取得這些金鑰,輸入後自動儲存到 macOS Keychain
- **當 API 金鑰無效或過期時**: 系統在呼叫 API 時檢測到 401/403 錯誤,立即停止並顯示「[服務名稱] API 金鑰無效或已過期,請前往設定頁面更新」,並提供快速跳轉到 API 金鑰管理介面的按鈕
- **當快取目錄 ~/Library/Caches/YTMaker3 不存在時**: 系統首次啟動時自動建立該目錄,若因權限問題無法建立,顯示警告並禁用快取功能,每次都重新生成圖片
- **當圖片快取超過 1000 張或佔用空間過大時**: 系統在每次啟動或生成新圖片後檢查快取,自動刪除最舊的(根據最後存取時間)圖片直到符合保留策略(最多 1000 張或 30 天內),並在設定頁面顯示當前快取使用情況
- **當使用者選擇的專案輸出儲存位置不存在或無寫入權限時**: 系統在儲存前驗證目錄存在性和權限,若失敗則提示「無法存取所選位置,請選擇其他目錄」,並重新顯示目錄選擇對話框
- **當 API 服務暫時無法連線時**: 系統在執行任何 API 呼叫(Google TTS、Gemini、Replicate、D-ID、YouTube)前檢查網路狀態;若連線失敗或 API 回傳錯誤,立即停止當前階段並顯示清晰的錯誤訊息(如「無法連線到 Google TTS 服務,請檢查網路連線後重試」),不繼續下一階段
- **當圖片生成失敗時**: 系統針對單張圖片失敗自動重試最多 2 次;若 2 次重試後仍失敗,停止整個專案並報錯(如「第 3 段圖片生成失敗,已重試 2 次,請檢查 Replicate API 狀態或修改提示詞」)
- **當文稿為空或過短時**: 系統在文稿輸入階段驗證文字長度;若少於 50 字,顯示警告「文稿過短,建議至少 50 字以獲得更好的影片效果」;若為空,禁止進入下一步並提示「請輸入文稿內容」
- **當文稿過長(超過 30 分鐘預估長度)時**: 系統根據平均語速(如每分鐘 250 字)預估影片長度;若超過 30 分鐘,顯示警告「文稿過長,預估影片長度超過 30 分鐘,可能影響生成速度和成本,是否繼續?」
- **當 YouTube OAuth Token 過期時**: 系統在嘗試上傳前驗證 Token;若過期,顯示提示「YouTube 授權已過期,請重新登入」並引導使用者重新進行 OAuth 認證
- **當使用者上傳的人像圖片尺寸不符時**: 系統驗證圖片比例是否為 16:9;若不符,顯示錯誤「圖片比例必須為 16:9(建議 1920x1080),目前上傳的圖片為 [實際尺寸]」並拒絕上傳
- **當字幕內容過長導致單行無法顯示時**: 系統自動切分長句為多段字幕,確保每段字幕在畫面上顯示時間不少於該段配音的時間長度,並在預覽中顯示切分效果
- **當 D-ID 對嘴影片生成時間過長時**: 系統顯示進度提示(如「對嘴影片生成中,預計需要 2-3 分鐘」),若超過 5 分鐘仍未完成,提示使用者是否繼續等待或取消對嘴功能
- **當快取的圖片 hash 發生碰撞時**: 系統在檢查快取前計算提示詞的 SHA-256 hash;若發現碰撞(極低機率),優先使用新生成的圖片並更新快取
- **當使用者嘗試載入損壞的專案檔案時**: 系統驗證專案檔案的 JSON 結構;若損壞,顯示「專案檔案已損壞,無法載入」並提供「查看錯誤詳情」選項顯示技術細節

## Requirements *(mandatory)*

### Functional Requirements

#### 文稿輸入與處理
- **FR-001**: 系統必須提供文字輸入框,支援繁體中文輸入,允許使用者貼上或輸入至少 10,000 字的文稿
- **FR-002**: 系統必須驗證文稿長度,若為空或少於 10 字則禁止進入下一步,並顯示提示訊息

#### 語音合成
- **FR-003**: 系統必須使用 Google Cloud TTS 自動將文稿轉換為繁體中文配音音檔
- **FR-004**: 系統必須提供下拉選單列出所有可用的繁體中文聲音選項供使用者選擇
- **FR-005**: 系統必須在語音合成完成後輸出音檔和時間標記(每個字或詞的開始/結束時間)

#### 腳本生成
- **FR-006**: 系統必須使用 Gemini API 自動將文稿切分為段落(每段對應一個畫面)
- **FR-007**: 系統必須為每個段落生成圖片描述提示詞(用於後續圖片生成)
- **FR-008**: 系統必須根據語音合成的時間標記自動為每個段落分配對應的時間軸
- **FR-009**: 系統必須允許使用者查看和修改 Gemini 的 system prompt,以調整腳本生成邏輯

#### 腳本編輯
- **FR-010**: 系統必須顯示生成的腳本,包含段落內容、時間軸和圖片提示詞
- **FR-011**: 系統必須允許使用者編輯任何段落的文字、時間和圖片提示詞
- **FR-012**: 系統必須提供圖片風格選項:「寫實風格」、「可愛插畫」、「中國古風」、「兒童風格」,使用者必須從中選擇一種
- **FR-013**: 系統必須提供 D-ID 對嘴設定選項:「不使用」、「僅開頭第一段」、「僅結尾最後一段」、「開頭+結尾」
- **FR-014**: 若使用者選擇使用 D-ID 對嘴,系統必須允許上傳 16:9 比例(建議 1920x1080)的人像圖片,並驗證圖片尺寸

#### 圖片生成
- **FR-015**: 系統必須使用 Replicate FLUX 根據腳本中的圖片提示詞批次生成圖片
- **FR-016**: 系統必須生成 1920x1080 (16:9) 解析度的圖片
- **FR-017**: 系統必須在單張圖片生成失敗時自動重試最多 2 次,若 2 次後仍失敗則停止整個專案並報錯
- **FR-018**: 系統必須支援圖片快取機制,根據提示詞的 hash 值檢查是否已有相同圖片存在,若存在則直接使用快取

#### 對嘴影片生成
- **FR-019**: 若使用者選擇使用 D-ID 對嘴,系統必須使用上傳的人像圖片和對應段落的音檔呼叫 D-ID API 生成對嘴影片
- **FR-020**: 系統必須根據使用者選擇(僅開頭/僅結尾/開頭+結尾)生成對應段落的對嘴影片

#### 影片編輯預覽
- **FR-021**: 系統必須提供影片預覽窗口,即時顯示組合後的影片畫面(包含圖片/對嘴影片、字幕、Logo)
- **FR-022**: 系統必須提供字幕編輯功能,允許使用者調整:位置、字型、字體大小、文字顏色、陰影顏色、邊框顏色、底色及底色尺寸
- **FR-023**: 系統必須將長句自動切分為單行字幕,確保每行字幕不超過畫面寬度
- **FR-024**: 系統必須允許使用者上傳 Logo 圖片,並透過拖曳介面定位 Logo 在畫面中的位置
- **FR-025**: 系統必須即時預覽字幕和 Logo 的調整效果
- **FR-026**: 系統必須允許使用者選擇任一張生成的圖片並下載為檔案(供製作自訂縮圖使用)

#### 影片合成
- **FR-027**: 系統必須使用 FFmpeg 將圖片(或對嘴影片)、配音、字幕、Logo 合成為單一 MP4 影片檔案
- **FR-028**: 系統必須為圖片添加動畫效果,包含橫移、縮放、淡入淡出
- **FR-029**: 系統必須根據語音時間標記同步疊加字幕,確保字幕出現時間與配音一致
- **FR-030**: 系統必須在影片中疊加 Logo(若使用者有設定)

#### YouTube 上傳
- **FR-031**: 系統必須支援 YouTube OAuth 2.0 認證,允許使用者授權應用程式存取其 YouTube 帳號
- **FR-032**: 系統必須支援至少 1 個 YouTube 帳號的管理(登入、登出、切換)
- **FR-033**: 系統必須在 Token 過期時提示使用者重新認證
- **FR-034**: 系統必須允許使用者選擇要上傳的頻道(若帳號有多個頻道)
- **FR-035**: 系統必須允許使用者設定影片標題、描述、標籤、隱私設定(公開/不公開/私人)、分類
- **FR-036**: 系統必須允許使用者上傳自訂縮圖(由外部工具如 Canva 製作)
- **FR-037**: 系統必須允許使用者設定排程發布時間,在指定時間自動上傳影片

#### API 用量統計
- **FR-038**: 系統必須在專案完成後顯示 API 用量統計,包含:Gemini 呼叫次數與費用、Google TTS 字數與費用、Replicate 圖片數量與費用、D-ID 使用次數與費用(若有使用)、YouTube API 配額使用量、總計費用

#### 專案管理
- **FR-039**: 系統必須允許使用者在任意製作階段儲存專案到本地檔案,專案檔案格式為 JSON (.json)
- **FR-040**: 系統必須允許使用者載入已儲存的專案,恢復所有設定並跳轉到上次離開的階段
- **FR-041**: 系統不需要提供版本控制功能(僅保存最新狀態)
- **FR-042**: 系統必須允許使用者選擇專案輸出檔案(影片、音檔、圖片、腳本)的儲存位置,預設為使用者文件/YTMaker3 目錄
- **FR-043**: 系統必須記住使用者上次選擇的儲存位置,並在下次建立新專案時作為預設值,使用者可選擇沿用或修改

#### 範本功能
- **FR-044**: 系統必須允許使用者將字幕樣式、Logo 位置、圖片風格偏好儲存為範本
- **FR-045**: 系統必須允許使用者在新專案中套用已儲存的範本,自動套用所有設定

#### 圖片快取管理
- **FR-046**: 系統必須將圖片快取儲存在 macOS 標準快取目錄(~/Library/Caches/YTMaker3)
- **FR-047**: 系統必須提供自動清理機制,保留最近 30 天或最多 1000 張快取圖片(以先達到的條件為準)
- **FR-048**: 系統必須提供手動查看和清除快取的功能

#### 批次製作
- **FR-049**: 系統必須允許使用者匯入多個文稿檔案(如 .txt、.md)
- **FR-050**: 系統必須允許使用者選擇範本並套用到所有匯入的文稿,批次生成影片
- **FR-051**: 系統必須允許使用者為每部批次生成的影片設定不同的排程上傳時間
- **FR-052**: 系統必須採用序列處理策略,一次處理一個專案,確保穩定性並避免 API 速率限制

#### API 金鑰管理
- **FR-053**: 系統必須使用 macOS Keychain 安全儲存所有 API 金鑰(Google TTS、Gemini、Replicate、D-ID、YouTube)
- **FR-054**: 系統必須在首次使用時提示使用者輸入各項 API 金鑰,並自動儲存到 Keychain
- **FR-055**: 系統必須提供 API 金鑰管理介面,允許使用者查看(遮罩顯示)、修改或刪除已儲存的金鑰

#### 錯誤處理
- **FR-056**: 系統必須在任何階段出錯時立即停止,不繼續下一階段,並顯示清晰的錯誤訊息(說明問題原因,不記錄無用 log)
- **FR-057**: 系統必須在執行任何 API 呼叫前檢查網路連線狀態,若無網路則提前報錯

### Key Entities

- **專案(Project)**: 代表一次完整的影片製作流程,儲存為 JSON 格式檔案,包含:文稿內容、語音設定(選擇的聲音)、腳本資料(段落、時間軸、圖片提示詞)、圖片風格選擇、D-ID 對嘴設定、輸出檔案儲存位置、生成的音檔路徑、生成的圖片路徑、生成的對嘴影片路徑(若有)、字幕樣式設定、Logo 設定、YouTube 上傳資訊(標題、描述、標籤、隱私、排程時間)、API 用量統計
- **腳本(Script)**: 代表經過 Gemini 處理的文稿結構,包含多個段落(Paragraph),每個段落有:段落文字、開始時間、結束時間、圖片描述提示詞
- **段落(Paragraph)**: 腳本中的一個單位,對應影片中的一個畫面,包含:文字內容、時間範圍、圖片提示詞、生成的圖片路徑或對嘴影片路徑
- **範本(Template)**: 儲存可重複使用的設定,包含:字幕樣式(字型、大小、顏色、位置、陰影、邊框、底色)、Logo 圖片路徑和位置、圖片風格偏好(寫實/插畫/古風/兒童)
- **圖片快取(Image Cache)**: 儲存在 ~/Library/Caches/YTMaker3 目錄,關聯:提示詞 hash 值(用於查詢)、圖片檔案路徑、生成時間、最後存取時間(用於自動清理)
- **API 用量記錄(API Usage)**: 追蹤單一專案或批次專案的 API 消耗,包含:服務名稱(Gemini/TTS/Replicate/D-ID/YouTube)、呼叫次數或用量(如 TTS 字數、Replicate 圖片數)、預估費用
- **批次任務(Batch Job)**: 代表一次批次製作,包含多個專案,共用範本設定,採用序列處理(一次處理一個專案),每個專案有獨立的排程上傳時間
- **使用者偏好設定(User Preferences)**: 儲存使用者的應用程式設定,包含:上次選擇的專案輸出儲存位置、API 金鑰(儲存在 macOS Keychain)、圖片快取清理策略

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 使用者可以在 10 分鐘內完成一部 3-5 分鐘影片的製作(從文稿輸入到影片合成完成),不包含 API 處理時間
- **SC-002**: 系統能夠成功處理 50-10,000 字的文稿,生成對應長度(1-30 分鐘)的影片,不發生記憶體溢位或崩潰
- **SC-003**: 圖片生成成功率達到 95% 以上(包含 2 次重試機制),失敗時提供明確錯誤訊息
- **SC-004**: 影片編輯預覽的即時性:字幕或 Logo 調整後,預覽窗口在 1 秒內更新畫面
- **SC-005**: 批次製作功能可以同時處理至少 10 個專案,每個專案獨立生成影片並正確套用範本設定
- **SC-006**: YouTube 排程上傳準時率達到 98% 以上(誤差在設定時間的 ± 5 分鐘內)
- **SC-007**: API 用量統計誤差率低於 2%(與實際 API 服務商帳單比對)
- **SC-008**: 90% 的使用者能夠在第一次使用時,無需查閱說明文件即可完成基本影片製作與上傳(從文稿輸入到 YouTube 發布)
- **SC-009**: 使用範本功能的使用者,製作第二部影片的時間比第一部縮短 50% 以上
- **SC-010**: 系統在網路正常但 API 服務暫時無法連線時,100% 的情況下能夠在 5 秒內偵測並顯示錯誤,不讓使用者無限等待

## Assumptions

- 使用者已具備 Google Cloud TTS、Gemini API、Replicate、D-ID、YouTube Data API 的有效 API 金鑰,系統提供安全的輸入和儲存介面(使用 macOS Keychain),但不負責申請流程
- 使用者的 macOS 系統已安裝 FFmpeg,或系統會在首次啟動時檢查並提示使用者安裝
- 影片動畫效果(橫移/縮放/淡入淡出)使用預設參數,不提供使用者自訂動畫速度或類型的功能(可在後續版本擴充)
- YouTube OAuth 2.0 認證使用 client_secrets.json 檔案,使用者需自行從 Google Cloud Console 下載並放置在指定目錄
- D-ID 對嘴影片生成時間預估為每段 2-3 分鐘,若實際生成時間過長(超過 5 分鐘),系統會提示使用者但不強制中斷
- 專案檔案使用 JSON 格式儲存,包含所有專案狀態和設定,預設儲存在使用者指定的位置(首次使用預設為使用者文件/YTMaker3)
- 圖片快取儲存在 ~/Library/Caches/YTMaker3,使用 SHA-256 hash 計算提示詞,自動清理保留最近 30 天或最多 1000 張圖片,使用者也可手動管理
- 字幕切分邏輯使用標點符號和時間標記,預設每行字幕不超過 20 個繁體中文字,不提供使用者自訂切分規則
- 批次製作採用序列處理,一次處理一個專案,確保 API 穩定性;排程上傳依賴系統時間和背景執行機制,若應用程式關閉則排程暫停,重新開啟後繼續執行
- API 費用估算基於公開的定價資訊(如 Gemini API 每 1M tokens 費用、Replicate FLUX 每張圖片費用),實際費用以服務商帳單為準
- 使用者上傳的 Logo 圖片格式為 PNG(支援透明背景),若為其他格式(如 JPG)則不支援透明效果
- 專案輸出檔案(影片、音檔、圖片、腳本)預設儲存在使用者文件/YTMaker3 目錄,系統會記住上次選擇的位置作為下次預設值
